# ゲーム設計・実装境界

「結晶システムを利用した戦略型デッキ構築カードゲーム」。収集→構築→CPU/対人の循環を段階的に提供する。

ルール・12種の数値の正本: [rules.md](rules.md)。M1はライフ5、初期手元3、先攻ドロー/攻撃なし、20枚、場4体、冷却とOD反動を維持。召喚直後の攻撃禁止など別ゲームのルールを追加しない。

| 項目 | 状態 | 検証/残課題 |
|---|---|---|
| 冷却・召喚・結晶移動・OD・攻撃・防御・山札切れ | テスト済み（既存Node） | iPhone通し操作は実機確認待ち |
| カード一覧/詳細、勝敗・再戦 | 実装済み | 縦横ブラウザと実機確認 |
| 俯瞰UI・操作案内・演出 | 実機確認待ち | Node51件・Chromium/WebKit計24件成功。[qa-report.md](qa-report.md) |
| デッキ構築・複数保存/選択対戦 | 実機確認待ち | [deck-system.md](deck-system.md)、Node62件・ブラウザ36件成功 |
| タイトル・チュートリアル・音/設定 | 未着手 | M1の後続。遊び方モーダルをチュートリアル完了と数えない |
| EASY/NORMAL/HARD | 未着手 | 現行をNORMAL基準とし、合法手の評価/先読み深さで差を作る。敵手札の参照や結晶付与は禁止 |

赤は速攻・OD・大ダメージ、青は冷却・妨害・制御、緑は資源・耐久・長期戦。M2の追加24〜36種は候補数であり必達ノルマではない。高レア=上位互換を避け、生成による救済を設ける。

既存の固定シード2方針と7条件比較は維持。M4へ向け、デッキ組み合わせ×先後×複数シードの勝率・平均ターン・カード使用/依存を追加する。現行ボット結果だけでバランスを確定しない。大きな変更は測定条件と採否・理由を残す。
