# ランキング設計（M4、未着手）

M3の確定勝敗/履歴が安定してから開始する。内部MMRと表示ランク（BRONZE/SILVER/GOLD/PLATINUM/DIAMOND/MASTER）を分離。境界、初期レート、計算式、リセット幅、シーズン期間は未決定。

マッチ結果をサーバーから一度だけ受領し、両者のレート/履歴を同じトランザクションで更新する。クライアントの勝利報告でレートや報酬を増やさない。引き分け、降参、切断、無効試合を区別し、監査用matchIdと旧/新レートを保持する。

待機時間に応じてMMR幅を段階拡張し、最大差・タイムアウトを設ける。人口不足時は待機状況と再試行を示し、ランク戦の対戦相手を無告知でCPUへ置換しない。フレンド戦をランク報酬に流用しない。

シーズンIDで順位/報酬を分離。シーズン確定時刻と進行中試合の帰属を仕様化する。報酬は見た目を優先し、能力の優位を買える設計を避ける。

必須検証: 二重結果、並行更新、自己対戦/談合の検出設計、古いシーズンへの書込、境界時刻、同率順位、報酬再受領、DBロールバック、待機人口不足、先後/デッキ対面の偏り。実装とテストはいずれも未着手。
