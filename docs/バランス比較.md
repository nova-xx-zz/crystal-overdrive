# バランス比較設計

## 目的
Web版「結晶オーバードライブ」の早期決着（現行はボット対CPUで約3〜4ターン）について、正式なゲームの数値を変更せずに調整候補を比較する。

## 対象・不変条件
- 変更する項目は `START_LIFE`、`START_STOCK`、`OD_RECOIL` の3つのみ。
- シナリオは **Node.js VMに読み込む `cards.js` 内の定数だけ**を置換する。ブラウザ用の `web/cards.js` 自体は変更しない。
- デッキ20枚、カード12種類とその効果、ユニット上限は現行のまま。
- 1つの候補につき**1要素だけ**変えて比較。異なる要素を同時変更した影響は次のフェーズで検証する。

## シナリオ
| ID | ライフ | 初期結晶 | OD反動固定値 | 目的 |
|---|---:|---:|---:|---|
| baseline | 5 | 3 | 2 | 現行の基準 |
| life6 | 6 | 3 | 2 | 決着ターンを遅らせられるか |
| life7 | 7 | 3 | 2 | ライフ増加の追加影響 |
| stock2 | 5 | 2 | 2 | 序盤の召喚速度 |
| stock4 | 5 | 4 | 2 | 序盤のテンポ上昇 |
| recoil1 | 5 | 3 | 1 | ODリスクの軽減 |
| recoil3 | 5 | 3 | 3 | ODリスクの増加 |

※OD反動の総量は「上限超過分＋固定値」。

## 実行方法
Node.js 22以上、追加パッケージ不要。

```sh
node scripts/balance-scenarios.cjs --games 100 --seed 20261031
node scripts/balance-scenarios.cjs --games 100 --seed 20261031 --json
node --test tests/*.test.cjs
```

勝率とターンの基準差は、**同じ方針・同じシードのbaseline**に対して表示する。勝率差の単位はパーセントポイント。

## 評価指標と判断
1. 平均決着ターンと最短・最長ターン（プレイ時間の目安）。
2. 固定戦略ボット `rush` / `reserve` の勝率と差（特定戦略が極端に有利かの仮説）。
3. 山札切れ・未決着が増えないか。現行シミュレーターでは試合50半ターンで打ち切る。
4. 追加候補を検討する際は、必ず**同一seed・同一試合数・同一ボット方針**で再計測する。

## 制約
- ボットの結果は**人間の勝率ではない**。95%信頼区間などの統計評価も現段階では行わない。
- `rush` と `reserve` は単純な固定戦略であり、ODを積極活用しない。OD反動変更の影響が小さくても、効果が無意味とは限らない。
- ランダムシードは揃えるが、設定変更によって行動回数や乱数消費順は変わりうる。厳密な同一展開の比較ではない。
- 比較後に本番採用候補を選び、iPhone実機での操作感・ゲームのテンポを確認してからルール変更を検討する。
- 現時点ではパラメータを正式版に反映しない。

## 計測結果（2026-10-31）

条件：固定シード `20261031`、各候補につき `rush` / `reserve` それぞれ100試合（計1,400試合）。
自動テスト29件成功。比較前のbaseline結果（rush勝率79%、reserve勝率54%）と一致。

| 候補 | rush勝率 | reserve勝率 | rush平均ターン | reserve平均ターン |
|---|---:|---:|---:|---:|
| baseline | 79% | 54% | 3.17 | 3.82 |
| life6 | 51% | 37% | 3.50 | 4.01 |
| life7 | 71% | 36% | 3.92 | 4.23 |
| stock2 | 41% | 38% | 3.97 | 4.19 |
| stock4 | 68% | 28% | 3.08 | 3.42 |
| recoil1 | 79% | 54% | 3.17 | 3.82 |
| recoil3 | 79% | 54% | 3.17 | 3.82 |

すべてのシナリオで未決着0試合。[CIの実行ログ](https://github.com/nova-xx-zz/crystal-overdrive/actions/runs/41186363118) に各候補の内訳を記録。

### 初期評価
- **life6**：現行からの変更が比較的小さく、試合を少し長くできるため、次の実機比較候補。
- **stock2**：決着の遅延幅は大きいが、プレイヤーの序盤の選択肢を狭める可能性がある。体感検証が必須。
- **life7**：試合時間延長の選択肢だが、テンポ悪化の懸念も比較する。
- **stock4**：さらに短期決着になりやすいため、現時点の「試合を延ばす」目的には合わない。
- **recoil1 / recoil3**：今回の固定ボットでは勝率・平均ターンとも変化なし。OD使用回数などの計測がまだなく、影響なしとは判断できない。

### 今後の検証
1. 初期ライフ6、初期結晶2を中心に、実機で面白さ・操作テンポを確認。
2. ODを積極活用する第3のボット方針を追加し、OD使用回数と結晶消費を計測する。
3. 複数シード・試行数増加による安定性を確認する。
4. 正式パラメータ変更が必要と判断された場合は、`docs/rules.md` の仕様変更を**別PR**として提案する。
