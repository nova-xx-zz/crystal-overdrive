# 結晶オーバードライブ（仮）ルール v0.1

「資源を取り合う駆け引き」に着想を得た、オリジナルの対戦カードゲーム。試作版はWebで1対CPU。

## コンセプト
- 同じ「結晶」を、支払い・ユニットの維持・強化の3つで取り合う
- 差別化の核：①2段階の冷却 ②オーバードライブ（過負荷） ③中央の結晶プール

## 基本数値（調整用）
- ライフ5／最初の手元の結晶3／最初の手札4／場のユニットは最大4体／デッキ20枚
- オーバードライブ：上限＋2個まで乗せられる。反動は「超えた分＋2個」

## 結晶の置き場
手元（すぐ使える）／熱い → 冷めた（支払い済み。2ターンかけて手元へ戻る）／ユニットの上

## ターンの流れ
1. ユニットを回復。冷めた結晶→手元、熱い結晶→冷めた。結晶+1
2. ライフが相手より少なければ、中央プールから結晶を1個獲得
3. 1枚引く（先攻の1ターン目はドローも攻撃もなし）
4. メイン：召喚（コストを払う＋手元から1個をユニットに乗せる）、マジックを使う、結晶の乗せ替え（ユニットには最低1個）
5. 攻撃：1体につき1ターン1回。攻撃したユニットは疲労。相手は回復しているユニットでブロックでき、パワーの低い方が退場（同じなら両方）。ブロックされなければライフ−1。削れた結晶は中央プールへ
6. 終了：オーバードライブ中のユニットは「超えた分＋2個」が熱い状態になる。0個になったら退場

## ユニットの強さ
結晶の数でLv1/Lv2が決まる。上限を超えるとオーバードライブになり、パワーアップして攻撃時に特殊効果が発動する。

## 今後の検討
- 決着が3〜4ターンと早めなので、ライフ・初期の結晶数・オーバードライブの反動を調整する
- レーン制や拠点の制圧ポイントを追加するか
- 色ごとの個性づけ（紅=攻撃、蒼=結晶の操作、翠=耐久・資源）
