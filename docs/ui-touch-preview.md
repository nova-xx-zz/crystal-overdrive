# 縦持ち・横持ち UI タッチ試作（2026-11-09）

## 目的
提供ラフ（縦／横）を参考に、結晶オーバードライブの現行ルールを変更せずに画面と操作感を検証する。

## 起動
`web/layout-touch-preview.html` をブラウザで開く。Web版の既存 `web/index.html` は変更しない。

## レイアウト
- 縦持ち: 相手情報 → 相手の場 → フェイズ／自分の場 → 自分の情報・手札・操作
- 横持ち: 相手情報・場を横並び、中央はフェイズと自分の場、下段に自分の情報・手札・操作
- 手札は横スクロール。カード選択時は詳細をオーバーレイ表示。右上の「×」で閉じる。
- 結晶の残量、熱い／冷めた結晶、中央プールを維持。

## 動作（従来のゲームエンジンを流用）
- 手札選択 → 詳細 → ユニット召喚／マジック
- 自軍ユニットを選択 → 結晶の増減（上限超過で OD）
- 攻撃フェイズへ → 自軍ユニット選択 → 攻撃
- ターン終了 → CPU 行動 → ブロック選択 → 自分のターン
- ヘルプ・リスタート

## 注意
画像にある「HP20」「マナ3/5」「墓地」はレイアウトのイメージとしてのみ参照。現行ゲームはライフ結晶5・手元／熱い／冷めた結晶・最大4ユニット。**ゲームルールは変更していない**。
スマホ縦横での実機タップ領域・文字サイズ・Safe Area は未検証。レイアウトを採用する前に iPhone Safari と実機で確認する。これは本番 Web 画面の置換ではない。
