# iPhone操作性の改善（Web版）

## 目的
iPhone Safariでカードゲームを縦持ちしたときに、ターン操作がスクロールに埋もれにくく、手札やブロック選択を確実にタップできるようにする。

## 変更仕様（第1段階）
- 画面下部の「攻撃フェイズへ」「ターン終了」を `position: sticky` で表示する。長い画面ではスクロール中も操作しやすくする
- Safe Area（ホームインジケーター、ノッチ）の余白を `env(safe-area-inset-*)` で確保する
- 手札の横スクロールにスナップを追加し、選択中のカードが上方向に少し動いても切れないよう手札上部の余白を確保する
- 通常ボタンの最小高さ44px、ブロック選択肢52pxを確保する
- カード・ユニットの選択状態に `aria-pressed` を付与し、対象選択中の敵ユニットへ「対象に指定」の音声ラベルを追加する
- カード効果、結晶消費、ターン進行など対戦ロジックは変更しない

## 実機確認
- iPhone Safariで縦画面の上・中央・下へスクロールしても操作バーが押しやすい
- ホームインジケーターがボタンと重ならない
- 手札を横にスワイプしてから選択し、カード名・説明・召喚ボタンが確認できる
- 相手の攻撃中にブロック選択モーダルが閉じず、選択肢が押しやすい
- iPhoneの文字拡大設定・画面回転・小さな画面でボタンやカードが極端に欠けない
- VoiceOverで手札とユニットの選択状態、効果対象が読み取れる

## 注意事項
この変更はCSSと音声ラベルの改善であり、iPhone実機テストに合格したことを意味しない。
Chrome / Androidのタッチや横画面も公開前に確認する。
