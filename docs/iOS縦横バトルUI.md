# iOSバトルUI（ラフ画準拠・縦／横）

更新日: 2026-11-09

## 概要
提供された縦持ち・横持ちのラフ画像に準拠して、Capacitor 8 / WKWebViewで表示する本番対戦画面を更新した。**操作試作HTMLではなく `web/index.html` が読み込む画面に適用**する。iOSネイティブプロジェクトはMacでの初回 `npm run ios:add` によって生成する（リポジトリには未収録）。

- 画面: `web/ui.js`（カード、シルエットSVG、画面構造）
- 意匠・縦横切替: `web/ios-battle.css`（`web/styles.css` の後から読み込む）
- 対戦: `web/game.js`、`web/cards.js`（同じゲームルールを維持）
- iOS同梱: `capacitor.config.json` の `webDir: "web"`、`web/index.html`
- 回転許可: `scripts/ensure-ios-orientations.cjs`（生成済み `ios/App/App/Info.plist` を更新）
- 回帰: `tests/ios-battle-ui.test.cjs`、既存の `tests/*.test.cjs`

## ラフ画をどこまで再現したか
- 明るいグレー／ホワイトの盤面、ダークグレーのラベル、青い結晶、ピンクのHPパネル、グリーンのターン終了ボタン。
- 上部「相手」: 円形アバター、HP、デッキ、墓地、相手の場。
- 中央: ターン数、メイン→バトル→エンド、中央プール、自分の場。
- 下部「自分」: 円形アバター、HP、コスト（結晶）、デッキ、墓地、手札、効果確認／ターン終了。
- カード: コスト円、単色シルエット、下端の数値。全カードアートをSVGでローカル描画。
- **縦向き**: 相手の情報 → 相手の場 → 進行状態 → 自分の場 → 自分の情報と手札 → 操作ボタン。
- **横向き**: 上段は相手情報／相手の場を左右に、中央はフェイズ／自分の場を左右に、下段は自分の情報／手札／山札を左右に。
- 手札は横スクロール。カードタップで下部詳細パネルが開き、召喚／マジック使用を行う。場のユニットタップで結晶の増減、バトルフェイズでは攻撃を行う。
- 設定メニューからカード一覧、遊び方、再戦。CPUのブロック選択モーダルを維持。

## 重要：ラフ画の数値・用語と現行ルールの違い
デザインのみを採用し、現在のゲーム仕様は維持する。ラフ画のプレースホルダー数値を、実際のゲーム状態として表示してはいけない。

| ラフ画 | 現行アプリ |
|---|---|
| HP 20 | 現行ライフ結晶（初期5）をHP欄に表示 |
| マナ3/5 | 上限のない「手元の結晶」を実値で表示。5点灯ゲージは表示装飾。熱い／冷めた結晶も表記 |
| 墓地（捨て札） | 使用済みマジックと退場ユニットをカウント。対戦ルールには影響しない |
| カードの3/2等の数値 | 現行のパワーと配置中の結晶数（防御値という概念は未導入） |
| 横向きの場5枠 | 実際の上限は4体。横の5枠目は非操作の装飾用。ルール変更するまで召喚できない |

## iPhoneでの確認手順
```sh
git fetch origin
git switch feature/ios-battle-screen-from-mockup-20261109
npm install
npm test
npm run ios:add        # 初回のみ。ios/App/App.xcodeproj が既存なら省略
npm run ios:prepare    # Webを同梱し、縦向きと左右横向きをInfo.plistに設定
npm run ios:open
```

XcodeのAppターゲットで署名Teamを設定し、iPhoneシミュレーターまたは実機を実行先に選ぶ。横持ち表示を確認するため、端末の「画面の向きのロック」を解除する。

※ Capacitor 8ネイティブプロジェクトの生成、Xcodeビルド、iPhone実機描画はこのリポジトリ作業環境では未実施。Xcodeを開いてビルドが通ったことを意味しない。
